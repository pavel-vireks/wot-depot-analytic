# WoT Depot Analytic

[English](README.md) · [Українська версія](README_ua.md)

**Когда у тебя в ангаре сотни танков, а ты уже не помнишь, что где установлено.** WoT Depot Analytict одной
кнопкой обходит весь ангар и показывает содержимое каждой машины:
оборудование, снаряжение, бустеры, снаряды, экипаж, стили и камуфляжи. Также по выбраному фильтру можно массово снять любое оборудование, просто отметь что хочешь снять, убедись что тебе это по карману и подтверждай.

**Клиент:** 2.4.0.0 · **Версия мода:** 0.4.0

## Для кого этот мод

Если вы собираете технику и вы заядлый коллекционе, то этот мод даст полную опись Вашей бесценной коллекции:

- **Вся коллекция в одном окне.** Мод проверен на ангаре из 750 танков. Отчёт
  собирается за пару секунд.
- **Отдельные фильтры для особой техники:** **коллекционная**,
  **премиумная**, **акционная**. Чекбоксы можно сочетать: например, «все
  коллекционные СССР 8 уровня».
- **Стили и кастомизация.** Видно, какой стиль или камуфляж стоит на каждой
  машине и для какого сезона («Зима», «Лето», «Пустыня» или «все сезоны»), а для
  камуфляжей ещё и на какой части танка.
- **Оборудование с учётом грейда.** Экспериментальное, боновое, трофейное и
  трофейное улучшенное в игре выглядят почти одинаково, а в моде различаются
  цветной полосой и подписью. Сразу видно, где стоит редкое оборудование, которое можно снять и переставить на другой любимый танк.
- **Склад.** На каждой плитке оборудования указано, сколько таких предметов
  лежит без дела. Предметы, которые лежат на складе тоже указаны.
- **Экипаж.** Все танкисты с перками. Отдельный фильтр **«экипаж с
  0-перком»** находит экипажи с бесплатным перком (например, «Боевое
  братство»).

## Прямо в клиенте игры

В подвале ангара, слева от «Меню», появляется кнопка. Она открывает
полноэкранный отчёт.

**Три вкладки:**

| Вкладка                 | Что показывает                                                                      |
|-------------------------|-------------------------------------------------------------------------------------|
| **Танки**               | Список машин. Клик по танку показывает, что на нём стоит                            |
| **Сводка по предметам** | Каждый предмет: на скольких танках стоит и на каких                                 |
| **Оборудование**        | Плитки с иконками из игры, разложенные по грейдам и классам, с остатком на складе   |
| **Снятие**              | Отдельная вкладка для снятия оборудования, обновляется сразу как вы в нее перейдете |

**Инструменты:**

- **Поиск по всему:** по танку, предмету, члену экипажа, стилю.
- **Фильтры:** нация, класс, уровень, категория; признаки «премиум /
  коллекционный / акционный»; содержимое танка («с экипажем», «с
  оборудованием», «со снаряжением», «снаряжённый»).
- **Сортировка** по любой колонке.
- **Переходы:** клик по предмету или плитке показывает все танки, где он
  стоит, вернуться можно кнопкой «назад».

**Пример:** нажали на плитку «Экспериментальная система заряжания» и сразу
видите все танки, где она стоит.

Кнопки **«Обновить»** и **«Открыть в браузере»**; закрыть окно крестик или Esc.

## Выгрузка в файлы

Каждый отчёт сохраняется в папку `tank_report` рядом с игрой:

- **HTML-страница**  тот же интерактивный отчёт, открывается в браузере.
  Подходит, чтобы показать коллекцию другу или посмотреть на втором мониторе.
- **CSV «длинный»**  одна строка на предмет, для сводных таблиц в Excel.
- **CSV «широкий»**  одна строка на танк, для быстрого просмотра.

Excel открывает оба CSV двойным кликом.

Отчёт в браузере также открывается сочетанием **Ctrl+F9** в Вашем системном браузере.

## Установка

1. Скачай [`wot_depot.wotmod`](https://github.com/pavel-vireks/wot-depot-analytic/releases/download/latest/wot_depot.wotmod)
   и [`net.openwg.gameface_1.1.6.wotmod`](https://github.com/pavel-vireks/wot-depot-analytic/releases/download/latest/net.openwg.gameface_1.1.6.wotmod).
2. Положи оба файла в `<папка игры>\mods\2.4.0.0\`.
3. Запусти игру. При первом запуске библиотека **один раз сама перезапустит
   клиент**  так она регистрирует окна модов.

Если `net.openwg.gameface` у тебя уже стоит (она идёт в комплекте со многими
модами, например modsListApi), вторую копию не клади  оставь одну, более
новую.



Без библиотеки мод тоже работает, но только через **Ctrl+F9** и браузер:
кнопки в ангаре не будет.

**Другой способ  папка `res_mods`:** распакуй
[`wot_depot_res_mods.zip`](https://github.com/pavel-vireks/wot-depot-analytic/releases/download/latest/wot_depot_res_mods.zip)
в папку игры. Не ставь оба способа сразу: файлы из `res_mods` перекрывают
`.wotmod`.

**После патча игры** папка модов меняется (например, `mods\2.4.0.0` → новая
версия). Перенеси туда и мод, и `net.openwg.gameface`.

## Настройка (необязательно)

Положи `tank_report.json` в папку с игрой:

```json
{
  "hotkey": "KEY_F9",
  "hotkeyRequiresCtrl": true,
  "browserMode": "system",
  "styleDetails": false,
  "hideCustomizationTypes": ["emblem"],
  "chunkSize": 25,
  "hangarButton": true
}
```

- `browserMode`: `system`  обычный браузер (по умолчанию), `off`  только
  файлы.
- `styleDetails`: `true`  расписывать детали стиля по отдельности.
- `hideCustomizationTypes`: какие типы кастомизации скрывать; пустой список 
  показывать всё.
- `hangarButton`: `false` убирает кнопку из ангара.

## Безопасноcть

- Мод ничего не отправляет в интернет. Для браузерной версии он поднимает
  небольшой веб-сервер, доступный только на вашем компьютере (`127.0.0.1`).
- Мод только читает данные ангара. Единственное исключение — снятие оборудования: оно
  выполняется только на вкладке **«Снятие»** и только после вашего подтверждения.
